# jpegkevin.com

Kevin Tang's personal photography site: a Vite + React single page, deployed to Vercel from `main`.

## Testing

- Run `npm test` (vitest, jsdom). Tests live beside their sources as `*.test.js` / `*.test.jsx` under `src/` and `plugins/`.
- `npm run lint` and `npm run build` must also pass before shipping.
